# Contributing

Original DANTE material is licensed under Apache-2.0 following owner confirmation.
See LICENSE for terms. No separate CLA or copyright assignment is imposed here.
Submit only material you are authorized to share and identify upstream provenance
and notices. Do not submit private employer/customer material.

Use focused changes, preserve the P0-P6 invariants and run the full offline suite
from README.md. Keep test assertions and exact counts truthful. Use synthetic local
fixtures, not providers, real credentials or personal paths. Record source/test
fingerprints and run whitespace, PII and secret checks before review. Do not infer
future qualification from the private baseline hash.

For security issues follow SECURITY.md. No push, public repository creation,
history rewrite, model download or provider call is authorized by this document.
